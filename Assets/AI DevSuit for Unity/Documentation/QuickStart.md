# 🚀 Quick Start

Get up and running with AI DevSuite in under 2 minutes.

---

## 1. Open the Setup Window

In Unity, go to:

Tools/ AI DevSuite / Tools → Setup Window

---

## 2. Enter Your API Key

AI DevSuite requires access to a third-party AI provider.

### Supported providers:

* OpenAI
* Anthropic

### Setup steps:

1. Create an account with your provider
2. Generate an API key
3. Paste your API key into the Setup Window

> 🔒 Keep your API key private. Do not share it.

> ⚠️ API usage costs are not included
> Costs depend on your provider and usage

> 💡 You can control costs by selecting different models

---

## 3. Start Using AI DevSuite

### 💻 Generate Code

* Go to: Tools/AI DevSuite → Vibe Coding
* Select a GameObject (drag & drop into the target field)
* Enter a prompt (example: *"Make the player move forward"*)
* Click **Generate Script**

---

### 🛠 Fix Errors

* Open the **Error Explainer**
* Unity console errors will appear automatically
* Click:

  * **Explain** → to understand the issue
  * **Fast Fix** → to apply automatic fixes

---

### 🎨 Generate Assets

* Go to: AI Graphics Tools
* Choose a tool (Texture, UI, Character, etc.)
* Enter a description
* Adjust quality settings if needed
* Click **Generate**
* Save the result

---

## ⚠️ No API Key?

If no API key is set:

* AI tools will be disabled
* The UI will guide you to complete the setup

---

## ✅ Done!

You're ready to build faster with AI inside Unity.

---

## 💡 Tips

* Use clear and simple prompts
* Start small and iterate
* Combine tools for better results
