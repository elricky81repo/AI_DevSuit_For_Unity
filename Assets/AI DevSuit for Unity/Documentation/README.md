# AI DevSuite for Unity

### Your AI Copilot for Code, UI & Assets

Build faster inside Unity with an AI-powered assistant that helps you generate code, fix errors, refactor scripts, and create 2D assets — all without leaving the Editor.

---

## ⚡ What is AI DevSuite?

AI DevSuite is an all-in-one AI toolkit designed to accelerate Unity development workflows.

Instead of switching between multiple tools, you can generate, improve, and apply results directly inside your project.

---

## 🧠 Core Capabilities

### 💻 AI Coding Assistant

* Generate scripts from plain English prompts
* Explain Unity and C# errors in simple terms
* Refactor and optimize existing code
* Add new functionality to current scripts
* Plan and generate multi-script solutions
* Built-in Copilot (chat, planning, teaching)

---

### 🎨 AI Graphics Tools

* Generate 2D characters
* Generate 2D objects
* Generate UI elements and UI packs
* Generate textures for materials with instant application
* Analyze your game UI and receive improvement suggestions

---

## 🧩 Main Tools Overview

* **Copilot** → Chat, planning, code generation, and teaching
* **Error Explainer** → Understand and fix errors quickly
* **Fast Fix** → Apply automatic fixes to common issues
* **Multi-Script Refactor** → Generate structured multi-file solutions
* **Character Generator** → Create 2D characters
* **UI Generator** → Generate UI elements and packs ready to use
* **2D Object Generator** → Create UI and game objects
* **Texture Generator** → Generate materials and textures
* **UI/UX Analyzer** → Evaluate UI for platforms (mobile, Steam, etc.)
