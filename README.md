# AI DevSuite for Unity

Proyecto y herramientas de desarrollo asistido por IA para Unity.

## Requisitos

- Unity `2022.3.62f3` (2022 LTS)
- Git

## Abrir el proyecto

1. Clonar este repositorio.
2. En Unity Hub, seleccionar **Add project from disk**.
3. Elegir la carpeta raíz del repositorio.
4. Abrir el proyecto con Unity `2022.3.62f3` y esperar a que Unity restaure los paquetes y regenere `Library`.

## Contenido versionado

El repositorio conserva `Assets`, `Packages` y `ProjectSettings`. Las cachés, archivos temporales, soluciones generadas por Unity, configuraciones locales y posibles secretos se excluyen mediante `.gitignore`.
